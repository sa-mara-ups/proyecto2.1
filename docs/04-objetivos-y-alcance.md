# Objetivos y alcance

## Objetivo general
Desarrollar una página web dinámica para que los estudiantes conozcan las especialidades del establecimiento y pueda aumentar las matrículas del liceo.

## Objetivos específicos

1. Diseñar una página web atractiva, clara y fácil de utilizar para los estudiantes.
2. Mejorar la difusión de la oferta educativa del establecimiento a través de una plataforma digital.
3. Presentar detalladamente las distintas especialidades que ofrece el establecimiento.
4. Incorporar imagenes, videos y contenido interactivo que permitan conocer mejor cada especialidad.

## Beneficiarios
Estudiantes y apoderados que buscan conocer las especialidades del establecimiento
